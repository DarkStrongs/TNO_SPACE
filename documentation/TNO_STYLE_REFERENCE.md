## 1. 色板（从截图取样）

| 用途 | 色值 | 说明 |
|---|---|---|
| 底色 | `#061116` | 近黑青，整窗平涂，**没有渐变、没有纹理** |
| 主线 / 强调 | `#5AC8C0` | 1–2px 边框、地图边界、图标、选中页签填充 |
| 次线 | `#3E7A78` | 内框、分隔线、未激活元素 |
| 高亮区块填充 | `#1B3F40` | 选中地区、悬停行（低饱和，不刺眼） |
| 正文 / 标签 | `#DFE6E0`（亮） / `#B4C4C2`（灰） | 标签和标题都用米白，**不用青色写正文** |
| 坏 / 警告值 | `#E07078` 珊瑚红 | 「Unavailable」「In Recess」「Conservative」 |
| 列表项 / 数值 | `#F0D050` 黄 | 案件名、概率、数量 |
| 好值 | `#80E090` 绿 | SUCCESS、GREAT |

TNO 色码对应：正文 `§F` / 灰 `§g`，红 `§R`，黄 `§Y`，绿 `§G`。**蓝色 `§D` 基本不出现**。

## 2. 框与分区
- **双线框**：大分区是外框 + 内缩 4–6px 的第二道框（法院页左栏、Pending Cases 区）。同一层级的框线粗细一致。
- **框套框**：信息分块靠嵌套方框，不靠底色差。块与块之间留 6–10px 黑缝。
- **表头格**：表格式小区块（Chief Justice / Composition）用 1px 线隔成格子，标题在格子顶行，内容在下面。
- **切角**：BAPD 左侧导航顶部是 45° 斜切线，窗口其余部分都是直角，不用圆角。
- 窗口装饰极少：标题栏下一条线，右上是方形的「i」和红色「X」按钮。

## 3. 字体与文字
- 大标题：等宽像素字（BAPD 用 VT323 风，Raiders 用细 Aldrich 风全大写），居中，米白色。
- 区块标题比正文大一级，居中，米白；可以加一条下划分隔线（RAIDING ESTIMATIONS）。
- **「标签：值」句式**：`The Docket is: Unavailable`，标签米白，值上色。这是 TNO 最常见的状态表达。
- 列表项文字居中，黄色；正文说明左对齐、行距宽松。

## 4. 控件
- **页签**：未选中 = 青色描边 + 黑底；**选中 = 整块青色填充 + 深色文字（反色）**。
- **列表行**：通长描边长条，右侧一个方形状态格（绿框 = 进行中 / 可用，红框 = 历史 / 不可用），再右侧是一根细滚动条。
- **进度条**：**分段竖纹条**，不是实心条。
  - 法院页：红色竖纹，按 4–5 大段分隔。
  - Raiders：青色段 vs 红色段，表示双方对比。
- **按钮**：
  - 普通按钮：白 / 米白描边的圆角矩形，大写文字（ASSIGN）。
  - 关键行动按钮：珊瑚红粗框大方块，红字（EXECUTE SPECIAL OPERATION）。
  - 加减按钮：绿色 + 方块、红色 − 方块。
- **下拉框**：青框，右端一个实心三角按钮格。
- **滚动条**：细青线 + 上下实心三角（我们 r9 的 NSP_right_slider 方向对）。

## 5. 插画 / 图标
- 插画是**线稿**：黑底上的单色细线（法官合影、地图边界、坦克）。和我们 R&D 的蓝图线稿方向一致。
- 图标是小号平涂像素图标，2–3 色，每个图标旁边常带一道短下划线（BAPD 设施）。
- 地图：只画边界线；高亮地区用 `#1B3F40` 平涂。

## 6. 交互
- 悬浮卡（BAPD）：细青框 + 顶部标题行 + 底部绿色行动提示（Click to Expand facility），出现时没有阴影和动画修饰。
- 左侧竖向导航：选中项是箭头形页签（▶）或圆角框住的图标，上下用实心三角翻页。

## 7. 与 TNO_SPACE 当前界面的差距（r12 已应用 1–4、6–8；第 5 条保留黄色角标作「当前」标记）
1. 页签选中态：现在是黄框 → 改为青色整块填充 + 深色字。
2. 进度条：研发卡片、队列、甘特条都是实心黄条 → 改为分段竖纹条。
3. 数值颜色：大量使用蓝色 `§D`（解锁、奖励、目的地）→ 改为米白标签 + 黄 / 绿 / 红值。
4. 卡片底色：带青色调的填充和表头底色 → 改为纯底色 + 线框，表头只用一条线隔开。
5. 选中框：黄色角标 → 可保留（TNO 也用黄色表示「当前」），或改为青色双线框。
6. 状态格：研发卡片右上角的色块 → 改为空心方框（绿 / 红 / 黄框）。
7. 行动按钮：「启动任务」「开始研发」→ 普通态用米白描边，关键行动用珊瑚红粗框。
8. 「标签：值」状态行：例如「研发槽：3/3 已满」，统一采用这种句式。
